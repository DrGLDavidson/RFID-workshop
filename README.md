# RFID-workshop Tutorial
This repository contains source code for the RFID tutorial, for working with data from computerised bird feeders. 

**The tutorial can be viewed on [this RFID Tutorial Website](https://drgldavidson.github.io/RFID-workshop/index)**

## Steps to get started:

1. Create and name a new folder locally on your computer from which you will work. This tutorial assumes you are working locally, not from a cloud. 
2. Download the data folder in this repository to your local folder.
3. Create a new R script for your own work and follow the tutorial (you may need to first follow Tutorial 1 "requirements and resources" to do this, depending on previous experience with R).

## Alternate viewing options: 
Copies of the tutorials have been saved in pdf and html format as separate files for each tutorial, should you wish to download them separatley and view them individually. These are found in the Markdown PDFs and Markdown HTML folders. Note that pdf files can be opened and viewed directly on github and html files need to be downloaded and opened in a browser (the latter format is better). 

The R markdown files with the raw R scripts are in the script folder

## Next steps:
Once you complete the tutorial with the example dataset, you should be ready to apply the code to your own datasets. This requires adjusting the code to fit your experiment, data, and naming conventions. 
Some of the code and steps provided in this code may or may not be necessary steps for your own datasets. Ensure you understand their purpose and whether it's suitable for your aims.

- For example, should you come across coding [issues and need help](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue).
